## Positionnement
- Marque : **NOVALYZ** — signature **« Mesurer. Comprendre. Progresser. »**
- **La plateforme de performance sportive** (pas une app de muscu, pas un SaaS générique, pas une salle de sport).
- Commence par muscu / prépa physique, ambition multisport + structures.
- Cibles : athlètes, coaches, préparateurs, clubs, centres de formation, académies, structures pro, fédérations.
- Architecture de marque : **NOVALYZ** (plateforme) → **NOVALYZ Athlete** · **NOVALYZ Coach** · **NOVALYZ Pro** (clubs/académies/structures).
- Message clé : **« NOVALYZ transforme les données d'entraînement en compréhension de la performance. »** (Mesurer = collecter · Comprendre = tendances/indicateurs · Progresser = meilleures décisions).

## Direction artistique
- Univers entre Apple / Whoop / Oura / Garmin / Strava / Linear / Stripe / Vercel / Notion / Nike Training — **sans copier**.
- Premium, Sport-Tech, minimaliste, technique, moderne, futuriste crédible, élégant, très visuel, data-driven, humain.
- Éviter : salle de sport, clichés bodybuilding, haltères partout, photos stock, gaming, néons, gradients agressifs, look crypto, template SaaS générique, surcharge de texte.
- Couleurs : noir/graphite très sombre + blanc cassé + gris neutres + **UNE** couleur d'accent (parcimonie, pas de rainbow).
- Typo : Geist / Inter / Manrope. Hiérarchie forte, gros titres, peu de texte, beaucoup d'espace.
- **Le produit est le héros visuel** : vrais écrans NOVALYZ / mockups très proches de l'interface, pas de photos stock.

## Structure (landing)
1. **Hero** : NOVALYZ · Mesurer. Comprendre. Progresser. · « La plateforme de performance sportive. » · court texte + CTA « Découvrir NOVALYZ » / « Voir la plateforme » + grand mockup produit.
2. **Le problème** : les données dispersées (séances, charges, RPE, volume, cardio, récup, ressentis) → NOVALYZ les rassemble. Peu de texte, visuel de convergence.
3. **Mesurer** : « Mesurer ce qui compte. » — cartes de données réelles (entraînement, charge, séries, reps, RPE, repos, volume, cardio, régularité, ressenti, récup).
4. **Comprendre** : « Des données. Une lecture. » — grande compo dashboard (progression, tendances, volume/balance musculaire, records, charge, évolution, cardio, état de forme).
5. **Progresser** : « Voir ce qui change. » — grands graphiques (progression/exercice, tonnage, records, régularité, volume, cardio, charge, tendances). Données fictives = clairement « exemples ».
6. **NOVALYZ Athlete** : « Votre performance, au même endroit. » — mockup smartphone + cartes flottantes.
7. **NOVALYZ Coach** : « Un regard plus précis sur chaque athlète. » — grand dashboard desktop (athlètes, alertes, état de forme, charge, progression, régressions, historique, programmes, communication, bilans).
8. **Suivi humain** : « La performance ne se résume pas à une charge. » — sommeil, énergie, fatigue, douleurs, ressenti, état de forme.
9. **NOVALYZ Pro** (vision) : « Une plateforme pensée pour aller plus loin. » — clubs, centres de formation, académies, structures, équipes, préparateurs. Dashboard **concept** (marqué « Concept/Vision »).
10. **Multi-sport** (vision) : « Un sport aujourd'hui. Plusieurs demain. » — foot, basket, rugby, tennis, athlé, cyclisme, natation, hand, volley, sports de combat… présentés comme **vision**, pas pris en charge aujourd'hui.
11. **Une plateforme** : schéma NOVALYZ → Athlete/Coach/Pro → Performance/Training/Load/Recovery/Data → multi-sport.
12. **Vision** : « Construire l'infrastructure de la performance sportive. » — Athlètes → Coaches → Clubs → Structures → Sport. Rester crédible.
13. **CTA final** : minimaliste — Mesurer. Comprendre. Progresser. · « Découvrir la plateforme » · novalyz.com.

## Navigation
Navbar simple : NOVALYZ · Produit · Athlete · Coach · Pro · Vision · + « Découvrir » / « Accéder à NOVALYZ ». Mobile : hamburger élégant.

## Signature visuelle
Créer une signature graphique NOVALYZ : N abstrait / courbe de progression / ligne de données / points connectés / évolution ascendante (N + data). Simple, reconnaissable, déclinable (site, anim, icône, Insta, vidéo, app).

## Animations
Premium mais discrètes : apparition au scroll, graphiques qui se dessinent, chiffres qui apparaissent, cartes qui bougent légèrement, interfaces révélées, transitions fluides, légère parallaxe, hover subtil, nav sticky. Pas d'explosions/particules/gaming/rotations/effets inutiles.

## Responsive
**Mobile first**, excellent iPhone/Android/tablette/laptop/grand écran. Mockups adaptés spécifiquement au mobile (pas juste une réduction desktop).
