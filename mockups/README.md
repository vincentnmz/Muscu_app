# Maquettes — Parcours athlète solo (Novalyz)

Maquettes d'écrans mobiles (PWA) du parcours athlète solo muscu, à la charte
Novalyz (bleu `#1A5FFF`, polices Michroma + Quicksand). **Réflexion visuelle
avant code** — rien n'est branché à l'app.

## Contenu
- `*.dc.html` — un fichier par écran (format « Design Component », éditable au
  bloc dans le canvas).
- `canvas.json` — disposition des écrans sur le canvas (positions, titres).
- `novalyz-parcours-solo.html` — **le canvas complet** : ouvre ce fichier dans
  un navigateur pour voir/déplacer les blocs et titres, et exporter en PNG/PDF.

## Écrans
Aujourd'hui · Mon entraînement (+ agenda) · Cardio (sélecteur + Hyrox) ·
Mon état (charge/récup, poids, ressenti) · Mes analyses (switch Muscu/Cardio,
sous-onglets, chiffres animés) · Conversations (Coach + IA) · Chat IA.
Bulle IA flottante sur tous les écrans.

Version canvas en ligne (éditable) : voir le lien partagé dans la conversation.
